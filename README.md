This is my public progress log for the **KodeKloud 100 Days of DevOps Challenge** a structured, lab-first learning journey across the complete DevOps stack.

Every day includes:
- ✅ The exact KodeKloud task completed
- 🛠️ Commands used and configurations applied
- 🐛 Bugs encountered and how I fixed them

No theory dumps. Just real terminal work, real errors, and real fixes.
