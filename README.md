# 🚀 100 Days of DevOps Challenge – KodeKloud

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**100 Days of DevOps: Hands-on learning with Linux, Docker, Kubernetes, Git, Ansible, CI/CD & Cloud using KodeKloud labs.**


## 📌 About This Repository
This repository shows my 100-day hands-on DevOps learning journey with KodeKloud. It includes daily tasks, configurations, troubleshooting, and real-world examples using Linux, cloud, containers, CI/CD, and automation.

## 🎯 Skills Covered

- **Linux Administration**: Users, permissions, networking, services, security basics  
- **Containers**: Docker images, containers, Compose, networking  
- **Kubernetes**: Pods, deployments, services, storage, debugging  
- **Version Control**: Git workflows, branching, merging  
- **Automation**: Ansible playbooks and task automation  
- **Web & Networking**: Nginx, Apache, SSL, load balancing  
- **Databases**: MySQL/MariaDB basics and troubleshooting  
- **Infrastructure as Code (IaC)**: Terraform fundamentals and YAML-based configs  
- **CI/CD**: Pipeline concepts and automation mindset  

## 🚀 Get Started in 5 Steps

1. ⭐ Save this repository to track your learning  
2. 🍴 Fork the project to create your own practice space  
3. Start from **Day 001** and follow the sequence  
4. Complete each task hands-on before checking solutions  
5. Share your progress with `#100DaysOfDevOps`
